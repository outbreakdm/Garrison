# Landing page (`/`)

Scope: the public landing page only. Visitor mode: Persuade. The dashboard, status, sign-in and 404 pages keep the incumbent world.

Audience and job: Discord gaming-community owners and admins comparing bots; they decide whether to add Garrison. Action: Add to Discord (the invite link), with Open the dashboard second. Proof: the real dashboard and real Discord messages, live reply time and uptime when present; no counts, quotes or logos. Constraints: CSP (no inline styles), art optional per slot, copy rules from PRODUCT.md.

Benchmark: Linear, Vercel, Raycast for craft; MEE6, Dyno, Carl-bot and discord.com for category fit.

## Direction contract

THESIS: The Discord-bot landing page played straight, at Linear craft. The dashboard is the hero and is shown doing its job, with Discord showing the result. Refuses emoji feature grids, invented server counts and the old HUD costume.

OWN-WORLD: Ink ground, rounded surfaces with hairline borders and soft depth, pill buttons. Volt lime only on the primary action and live states; indigo only as ambient light. Gabarito display, Geist body, Geist Mono numbers. Glossy 3D object art when supplied.

STORY: An owner sees the whole server run from one dashboard, believes it is safe (re-checks, undo, least privilege, free) and adds Garrison.

FIRST VIEWPORT: A centered two-line headline at up to 72px, a subline, two pill actions with Add to Discord first, and the live chip when /status has data. Below them, about 1100px wide, the dashboard's Security page: the Lockdown card and the Requests card, with a Discord window overlapping its lower right. Lock the server now is pressed, the request goes from Queued to Done, the lockdown message lands in Discord, and the card becomes the locked card with Lift lockdown (the undo). The result is in view on a 1440x800 screen.

FORM: canon (standing exit, chosen by the user), category standard; seed key 3b9d5f84.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
